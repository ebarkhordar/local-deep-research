Inline citation links now use the same canonical URL as the Sources block, so a source URL carrying `user:pass@` credentials no longer reaches the saved report or the live stream. It was previously rendered in the link target, and in the visible link text under the domain-based citation formats. Inline destinations now also drop tracking parameters and normalize the host, matching the bibliography entry for the same source, and a source whose URL field is not a string is skipped rather than rendered as a Python repr.
